This chatbot was created so that Bogotá's sports fans can view U-16 standings and rankings. We used for-in loops so that the lists can be 
viewed easily and in an organized manner. We also included options for users to return to the main menu or finish the chat session at any 
point. The chatbot covers 3 sports: basketball, volleyball, and soccer, with each sport containing 3 different standings. We implemented 
conditionals to register what the user wants to see based on the menu choices, and we also used these same conditionals so the user can 
smoothly navigate through the menu and options. To run the program, we decided to copy and paste the code into Google Colab, where anyone 
who accesses the shared public link that follows: 
https://colab.research.google.com/drive/1B9FlPTYijm6DgcUdbUXwaLjMbL41SH7T#scrollTo=T1rbr7NOg1nA and has a logged in Google account can not 
only execute the program directly on that same page, but also review the source code easily.
